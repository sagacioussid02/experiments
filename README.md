# Experiments

Two learning-by-building projects live here.

1. **[`manga-comic-generator/`](manga-comic-generator/)** — turn user-supplied characters (a photo + a backstory each) into a multi-page manga/comic: story generation, panel scripting, panel artwork, and page layout with speech bubbles, exported as a PDF. **In progress** — the pipeline runs end-to-end with a mock image backend; see its README to run it and DESIGN.md for why it's built the way it is.

2. **[`multi-rag-platform/`](multi-rag-platform/)** — a from-scratch platform hosting two structurally different RAG pipelines (unstructured-document RAG and structured/SQL RAG) behind shared abstractions, built as a deep-dive on a system-design interview question. **Design decisions captured, implementation not started yet** — see its README for the plan.
